# HelloCharts

## 概要

グラフ表示ライブラリ「ReCharts」の使い勝手や表現力の確認のためのサンプルアプリ。

棒グラフや円グラフといった基本形から、散布図や波形グラフといった表現まで確認。

## 主な使用技術
- React
- TypeScript
- Tailwind CSS
- Recharts
